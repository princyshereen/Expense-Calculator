# Personal Expense Calculator

A lightweight, browser-based expense tracker built with vanilla HTML, CSS, and JavaScript. Users can input their monthly income, log expenses by category, and instantly see a summary of total expenses, savings, and a category-wise breakdown — all without a page reload.

## Features
- Enter monthly income
- Add expenses with amount and category
- Automatic calculation of total expenses and savings
- Category-wise expense breakdown
- Reset option to start fresh
- Clean, responsive UI with no external dependencies

## Tech Stack
- HTML5
- CSS3
- JavaScript (Fundamentals)

## Usage
Simply open `expense_calculator.html` in any browser — no build steps or installations required.
